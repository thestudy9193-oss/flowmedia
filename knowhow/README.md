# 노하우 (칼럼) 운영 가이드

홈페이지 `/knowhow/` 탭. 숏폼대행·릴스대행·쇼츠대행·유튜브대행 검색 유입용 영상 제작 꿀팁 글.
**2일에 1편 예약 발행.** (1차: 2026-09-29 ~ 11-06, 20편)

## 글 쓰는 법

1. `knowhow/posts/YYYY-MM-DD-영문-slug.md` 파일을 만든다. 파일명 날짜 = 공개일.
2. 맨 위에 frontmatter:
   ```
   ---
   title: 제목 (메인 키워드 포함)
   description: 검색 결과에 보일 요약 1~2문장 (메인 키워드 포함)
   date: 2026-11-01
   category: 영상 기획 | 촬영 | 편집 | 운영 | 대행 가이드
   image: (선택) knowhow/images/ 안의 파일명. 생략하면 <slug>.jpg
   draft: (선택) true 면 공개 안 함
   ---
   ```
3. 본문 마크다운: `##` 소제목, `-`/`1.` 목록, `>` 인용, `**굵게**`, `[링크](url)`, `![설명](이미지)`, `---`.
4. 대표 이미지 1장(16:9, 글자 없음): `knowhow/images/<slug>.jpg`. 새 글이면 `knowhow/gen_images.sh` 의 `prompt_for` 에 장면 한 줄을 추가하고 `bash knowhow/gen_images.sh <slug>` (codex-image gen.sh 경유).
   글 상단 대표 이미지 + 목록 썸네일 + 공유 미리보기(og:image)에 같이 쓰인다.
5. `python3 tools/build_knowhow.py` → HTML 생성 확인 → 커밋·푸시.

## 예약 발행 구조

- 빌드 스크립트는 **date 가 오늘(KST) 이하인 글만** 공개 페이지로 만든다. 미래 날짜 글은 숨김.
- GitHub Actions `.github/workflows/knowhow-publish.yml` 이 **매일 00:05 KST** 빌드 → 바뀐 게 있으면 커밋 → Vercel 자동 배포.
- 그래서 글은 미리 몰아서 써서 푸시해 두면 된다. 사이트맵(`sitemap.xml`)도 같이 갱신된다.

## 키워드 전략

| 메인 키워드 | 비중 |
|---|---|
| 숏폼대행 | 월 5편 |
| 릴스대행 (인스타 릴스대행) | 월 4편 |
| 쇼츠대행 | 월 3편 |
| 유튜브대행 | 월 3편 |

- 메인 키워드는 title 또는 description, 첫 문단, 마지막 문단에 자연스럽게 1회씩. 도배 금지.
- 내용은 영상 제작 꿀팁 + 우리 노하우(11년차 대표·이사 기획, 내부 감독·PD 자체 장비 촬영·편집).
- **지어낸 수치·통계·고객 사례 금지.** 의료·전문직 글은 과장 표현(완치·100% 등) 금지.
